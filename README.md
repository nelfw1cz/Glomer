# PyForge (Electron)

Редактор Python с игровыми режимами и динамическим светом. Это перенос твоего Qt-проекта: логика режимов осталась, интерфейс сделан заново.

## Запуск

Нужны Node.js 18+ и Python 3 в PATH (`py`, `python` или `python3`).

```bash
npm install
npm start
```

`npm run dev` открывает то же самое с инструментами разработчика. `npm test` проверяет логику режимов и запуск Python (интерфейс для этого не нужен).

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| F5 или Ctrl+Enter | Запустить / остановить |
| Ctrl+O | Открыть файл |
| Ctrl+S, Ctrl+Shift+S | Сохранить, сохранить как |
| Ctrl+B | Фоновая картинка |
| Ctrl+T | Сменить тему (Neon, Jungle, Medieval) |
| Tab, Shift+Tab | Отступ, убрать отступ (работает и на выделении) |

Горячие клавиши работают и на русской раскладке.

## Режимы

- **Стандарт.** Панель шаблонов (for, def, try, class, with и другие).
- **Code-RPG.** +4 XP за каждую строку (Enter), +30 XP и +5 HP за успешный запуск, −18 HP за ошибку. Уровень требует 100 + (уровень − 1) × 50 XP. Смерть возвращает HP и отнимает 30 XP.
- **Карта связей.** Граф вызовов функций. Узлы можно таскать, Ctrl+колесо масштабирует.
- **Машина времени.** До 400 снимков кода, перемотка слайдером. В прошлом редактор только для чтения.
- **Заметки.** Маркер и стрелки поверх кода. Рисунки живут, пока открыто приложение.
- **Боты aiogram.** Шаблоны для Telegram-ботов на aiogram 3: каркас (токен, роутер, `/start`, запуск), хендлеры (команда, текст, callback, фото, документ, эхо), клавиатуры, FSM-анкета, middleware, доступ только для админов. Хендлеры вставляются перед `main()`, недостающие импорты добавляются сами, вставка отменяется одним Ctrl+Z. Для запуска нужен пакет: `pip install aiogram`.
- **RTX Light.** Свет, который можно перетаскивать: тени от кода, лучи между строками, блики на панелях.

## Структура

```
main.js              окно, диалоги, запуск Python
preload.js           единственный мост между страницей и системой
renderer/
  index.html
  styles.css         темы, стекло, анимации
  js/explorer.js     проводник: дерево папки, контекстное меню
  js/botwiz.js       окна: мастер ботов, фокус-ловушка для диалогов
  js/core.js         подсветка, граф, RPG, история, вставка шаблонов (без DOM, покрыто тестами)
  js/bots.js         шаблоны aiogram
  js/app.js          редактор, свет, режимы, интерфейс
test/                тесты логики и запуска Python
```

## Что изменилось по сравнению с Qt-версией

- Поиск Python больше не вешает окно: интерпретаторы проверяются асинхронно.
- Если Python не найден, процесс не остаётся висеть, а в консоли появляется подсказка.
- Остановка скрипта убивает всё дерево процессов (на Windows `py` запускает ещё один процесс).
- Ручная остановка не считается ошибкой для RPG и не отнимает HP.
- Граф находит и методы внутри классов, а вызов в комментарии не считается.
- Темы переключаются полностью, включая цвета подсветки кода.
- Фоновая картинка сохраняется при смене темы.

## Темы

Тема — это один JSON-файл. Встроенные лежат в `renderer/themes/`, свои кладём в папку пользователя
(кнопка **«Папка тем»** внизу откроет её; на Windows это `%APPDATA%\pyforge\themes`). Тема с тем же `id`, что у встроенной, заменяет её.
Перезапуск не нужен лишь при смене темы кнопкой, новые файлы подхватываются при старте.

```json
{
  "id": "mine",
  "name": "Моя тема",
  "vars": { "--bg": "#0b0f14", "--acc": "255,120,80", "--fg": "#e8e8e8" },
  "decor": { "type": "vines", "inset": 20, "colors": { "vine": "#c0701f", "leaf": ["#2fd37a", "#16a085"], "berry": "#ffa63d" } }
}
```

- `vars` — любые CSS-переменные (полный набор смотри в `neon.json`; недостающие берутся из дефолта). Значения с `url(...)`, `;`, `{}` отбрасываются.
- `decor.type` — `vines` (лианы), `frame` (золотая рамка), `brackets` (неоновые уголки), `map` (рваные обожжённые края карты с тлеющими угольками; цвета `table`, `ember`, `scorch`) или `none`. Всё рисуется кодом на canvas (`renderer/js/decor.js`), картинки не нужны.
- `decor.inset` — отступ интерфейса от края в px (0–40). Цвета: `#hex`, `rgb()` или имя.
- Эффекты темы (все необязательные): `"scheme": "dark" | "light"` (светлая схема подстраивает цвета контролов), `"texture": "none" | "paper"` (бумажная текстура на панелях), `"glass": "frost" | "liquid"` (жидкое стекло: фон малых панелей слегка искажается SVG-фильтром, а блюр и насыщенность берутся из `--glass-blur` и `--glass-sat`).
- Для светлых тем полезны переменные `--hl` (цвет наведения и линий, для тёмных `255,255,255`, для светлых цвет чернил), `--on-acc`, `--chip-fg`, `--gutter`, `--console-fg`, `--err`, `--vig`, `--edge-shade`, `--glass-edge`. Пример полного набора смотри в `pirate.json` и `liquid.json`.
- Ошибки в файле не ломают приложение: тема пропускается, а причина показывается всплывашкой.

## Мастер ботов и просмотр функций

- **Режим «Боты aiogram» → «＋ Создать бота…»**: вводишь токен (кнопка «Проверить» спросит у Telegram, чей он, только по клику), отмечаешь хендлеры, выбираешь папку.
  Создаётся `bot-1/` (затем `bot-2`, …; по умолчанию в `Документы/PyForge/bots`) с файлами `main.py`, `.env`, `requirements.txt`, `.gitignore`, `README.md`.
  Токен хранится только в `.env`, а `.gitignore` не даёт загрузить его на GitHub.
- **Карта связей**: двойной клик (или Enter на выбранном узле) по функции открывает окно только для чтения с её кодом вместе с декораторами. Есть «Копировать» и «К месту в редакторе».
- Сохранённый файл теперь запускается из своей папки, поэтому `.env` и относительные пути работают и по кнопке «Запустить».

## Проводник и вкладки

- **Проводник** (кнопка с папкой в заголовке или `Ctrl+Shift+E`; `Ctrl+Shift+O` — открыть папку). Дерево папки, раскрытие по клику, клик по файлу открывает его во вкладке.
  Правый клик (или `F2` / `Del` / клавиша меню): новый файл, новая папка, переименовать, показать в проводнике ОС, **удалить в корзину** (не навсегда).
  Стрелки двигают выбор, `→` / `←` раскрывают и сворачивают папку. Последняя открытая папка запоминается. Скрыты `.git`, `node_modules`, `__pycache__`, `.venv`.
- **Вкладки** над редактором: `Ctrl+N` новая, `Ctrl+W` закрыть, `Ctrl+Tab` / `Ctrl+Shift+Tab` переключение, средняя кнопка мыши закрывает. Точка на вкладке — несохранённые изменения. У каждой вкладки свои выделение, прокрутка, заметки и история «Машины времени».
- Один и тот же файл не открывается дважды. Переименование в проводнике обновляет вкладку. Если файл удалён в корзину, вкладка остаётся с кодом как несохранённая.
- Закрытие окна спрашивает про каждую несохранённую вкладку. Файлы больше 5 МБ и бинарные не открываются.
- Ограничение: после переключения вкладки `Ctrl+Z` не вернёт правки, сделанные до переключения (история отмены браузера сбрасывается).

## Настройки, анимации, обновления (0.3.0)

- **Настройки** (`Ctrl+,` или кнопка в статус-строке): масштаб интерфейса 70–160 % (также `Ctrl+=`, `Ctrl+-`, `Ctrl+0`), выбор темы, переключатель анимаций, проверка версий.
- **Анимации**: панель файлов выезжает слева, новая вкладка «всплывает», редактор плавно проявляется при смене вкладки. Выключаются в настройках (и автоматически, если в системе включено «уменьшить движение»).
- **О программе**: версия и список авторов — массив `AUTHORS` в `renderer/js/settings.js`.
- **Новая версия**: при запуске (через 4 с) спрашивается GitHub `releases/latest` репозитория из `package.json` → `repository` (сейчас `nelfw1cz/Glomer`). Ничего не скачивается: открывается страница релиза. Нет релизов или нет сети — молча. Можно «пропустить эту версию». Чтобы увидеть диалог, создай на GitHub релиз с тегом выше текущей версии (например `v0.4.0`).

## Запуск

- **Windows:** `start.bat` (двойной клик).
- **macOS:** `start.command` (двойной клик в Finder). В первый раз macOS может не дать запустить файл: нажми на него правой кнопкой → «Открыть». Если файл не исполняемый, в Терминале выполни `chmod +x start.command` в папке проекта.

## Коммит в git

Кнопка «Коммит» в нижней строке или `Ctrl+Shift+G`. Окно берёт папку, открытую в проводнике (или папку текущего файла), и показывает изменённые файлы с галочками. Пишешь сообщение, `Ctrl+Enter` или «Закоммитить».

- Коммит **только локальный**: `git push` нужно выполнить самому (терминал или GitHub Desktop). Приложение ничего не отправляет и не скачивает.
- Файлы вида `.env`, `*.pem`, `*.key`, ключи и `node_modules/`, `__pycache__/` помечены («секрет?» / «мусор») и по умолчанию не отмечены.
- Коммитятся только отмеченные файлы; то, что уже было в индексе, но не отмечено, остаётся как было.
- Нужен установленный `git` и настроенные `user.name` / `user.email`; если чего-то нет, окно скажет, что выполнить.
- Git видит файлы на диске: несохранённые вкладки окно предлагает сохранить кнопкой.

## Стекло как в iOS (экспериментально)

Тема **Liquid glass** рисует панели через WebGL-линзу (`renderer/js/lens.js`): фон преломляется у краёв, как у выпуклого стекла, с цветной каймой и бликами, которые следуют за курсором. Включается и выключается в настройках («Реалистичное стекло»). Работает только в этой теме и без своей фоновой картинки; если WebGL недоступен, остаётся обычное CSS-стекло. Нагружает видеокарту — на слабых ПК лучше выключить.

### Прозрачное окно

В настройках: «Прозрачное окно (виден рабочий стол)». Окно создаётся с системным размытием: Acrylic на Windows 11 и vibrancy на macOS (на Windows 10 пункт неактивен). На **Linux** окно просто делается прозрачным, а размытие рисует композитор: Hyprland (`decoration { blur { enabled = true } }`), KDE (эффект «Размытие» + принудительно для окна), GNOME (Blur my Shell). Подсказка есть в настройках, кнопка «Как включить размытие…». Выбор записывается в `window.json` в папке данных приложения и применяется **после перезапуска**. Лучше всего выглядит с темой Liquid glass: линза рисует края и блики поверх просвечивающего рабочего стола. Ползунок «Плотность стекла» там же: левее (до 0 %) — рабочий стол виден сильнее, края стекла почти прозрачные, а середина панели всё равно держит лёгкую подложку для текста, правее — панели плотнее и текст читается лучше. Настоящего преломления рабочего стола нет — картинку за окном рисует система.

## Агент (чат с моделью по API)

Кнопка «Агент» в нижней строке или `Ctrl+Shift+L`. Работает с любым OpenAI-совместимым API (`/v1/chat/completions`): адрес, модель и ключ задаются в «Настройки» панели. Это пока чат без инструментов: он ничего не меняет сам, код из ответа вставляется в редактор кнопкой «Вставить».

**Ключ** хранится только в главном процессе, зашифрованным средствами системы (`safeStorage`), и в интерфейс не возвращается. Если в системе нет хранилища ключей (часть Linux-окружений), задай его переменной окружения `PYFORGE_API_KEY`. Запросы идут только на указанный адрес (https, либо http для localhost), редиректы запрещены.

**Как экономятся токены:**
- по умолчанию уходит только выделение или функция под курсором, а не весь файл (можно выбрать «весь файл» или «без кода»);
- код получает только последний вопрос, в истории остаются одни вопросы и ответы; помнится последних N сообщений (по умолчанию 4, можно 0);
- ограничение длины ответа (по умолчанию 700 токенов) и короткая системная инструкция;
- перед отправкой показывается оценка токенов, кнопка «Что уйдёт» показывает запрос целиком;
- счётчик «↑вход ↓выход» за сессию и её лимит (по умолчанию 60 000 токенов);
- жёсткая защита от случайно огромного запроса;
- секреты (токены ботов, `sk-…`, `API_KEY=…`) скрываются из кода до отправки, файлы `.env` и ключи не отправляются вообще.

Совет: для вопросов по коду берёт маленькую модель, она в разы дешевле большой.
